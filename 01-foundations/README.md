# 🐍 Python Foundations

**A hands-on foundation in Python programming, problem solving, and object-oriented design.**

</div>

---

## What this section develops

* Core syntax, variables, data types, operators, and user input.
* Control flow using conditionals and loops.
* Reusable functions, parameters, return values, and scope.
* Lists, dictionaries, tuples, and nested data structures.
* Problem decomposition and algorithmic thinking.
* Object-oriented programming with classes, objects, inheritance, and composition.
* Modular organization across multiple Python files.
* Event-driven programming and graphical applications with Turtle.
* State management, randomness, collisions, and coordinate systems.
* Debugging, readable code, and progressive refactoring.

## Learning approach

Every exercise is completed through active problem solving. The objective is not simply to finish applications, but to understand the decisions behind the code and progressively build solutions with less external guidance.
