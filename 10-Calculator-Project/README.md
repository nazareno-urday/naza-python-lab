\## ⚙️ The experiment



Enter two numbers, choose an arithmetic operation, and calculate the result directly from the command line.



The calculator supports addition, subtraction, multiplication, and division. After each operation, the previous result can be reused in the next calculation or discarded to begin a new one.



\## 🧠 Practiced here



`Functions` · `Dictionaries` · `Loops` · `Operation mapping` · `Control flow` · `State reuse`



\## ▶️ Run it



```powershell

py main.py

```



No third-party dependencies required.
