## ⚙️ The experiment

Enter a starting number, choose an arithmetic operation, and calculate the result directly from the command line.

The calculator supports addition, subtraction, multiplication, and division. Each result can be reused in the next operation or discarded to begin a completely new calculation.

## 🧠 Practiced here

`Functions` · `Dictionaries` · `Loops` · `Operation mapping` · `Control flow` · `State reuse`

## ▶️ Run it

```powershell
py main.py
```

No third-party dependencies required.
