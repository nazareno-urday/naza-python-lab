## 🎨 The experiment

An interactive drawing application inspired by the classic Etch A Sketch.

The program listens for keyboard events and moves a virtual pencil across the screen. You can draw in any direction, rotate the pencil, move backward, and clear the entire canvas.

## 🎮 Controls

| Key | Action |
|:---:|---|
| `W` | Move forward |
| `S` | Move backward |
| `A` | Turn left |
| `D` | Turn right |
| `C` | Clear the canvas and return home |

## 🧠 Practiced here

`Event listeners` · `Callbacks` · `Functions` · `Keyboard input` · `Turtle graphics`

## ▶️ Run locally

```bash
python main.py
```

No external dependencies are required. Turtle is included with Python.
