## 🏁 The experiment

A graphical turtle racing game built with Python's Turtle module.

The player chooses a color before the race begins. Six turtles then move forward by random distances until one crosses the finish line.

At the end, the program announces the winning turtle and tells the player whether the bet was correct.

## 🎮 How to play

1. Run the program.
2. Enter one of the available colors:
   `red`, `green`, `blue`, `yellow`, `orange`, or `purple`.
3. Watch the turtles race.
4. Check the console to discover whether you won.

## 🧠 Practiced here

`Object creation` · `Lists` · `Loops` · `Randomization` · `Coordinates` · `User input` · `Turtle graphics`

## ▶️ Run locally

```bash
python main.py
```

No external dependencies are required. Turtle is included with Python.
