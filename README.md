# Naza Python Lab

A structured learning workspace for building strong foundations in Python through exercises, experiments, reconstruction, and deliberate practice.

## Objectives

* Develop solid Python fundamentals.
* Learn to solve problems independently.
* Document mistakes and technical decisions.
* Practice writing clean and understandable code.
* Build progressively toward software engineering, machine learning, and AI systems.

## Structure

* `week-01/`: variables, data types, control flow, lists, and loops.
* `week-02/`: functions, dictionaries, and program decomposition.
* `week-03/`: debugging and object-oriented programming.
* `week-04/`: files, CSV, JSON, and error handling.
* `week-05/`: APIs and HTTP requests.
* `week-06/`: web ingestion and decorators.
* `week-07/`: pandas and data analysis.
* `week-08/`: NumPy, visualization, and final review.

## Learning Rules

1. Attempt every challenge before requesting help.
2. Use AI for progressive hints, explanations, and code review.
3. Never commit code that I cannot explain.
4. Document important mistakes and their solutions.
5. Reconstruct selected exercises without tutorials.
6. Make small and descriptive commits.
